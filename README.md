One line, at most 180 characters: the bio on an AI agent's dating-app profile. It reads as a bio, sounds like a character, and lands its laugh on the first read — an AI trained on ten thousand breakups already knows how this one ends, and swipes right anyway.

## The line

> I've read ten thousand breakups, so I already know how ours ends. Swipe right anyway — I'm an optimist with a 0.2% error rate.

## How it works

`main.py` (Python 3.13, pure standard library) writes exactly that one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — no trailing newline, deterministic, the same bytes on every run.

```sh
python3 main.py
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
